# 🤖 Mohit AI Tools

A free, responsive collection of useful browser-based tools.

## Included tools
- QR Code Generator
- Age Calculator
- Calculator
- Unit Converter
- Text Counter
- Password Generator
- Stopwatch
- Color Picker

## How to publish on GitHub Pages
1. Create a new GitHub repository, for example `mohit-ai-tools`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. GitHub will provide your public website link.

## Note
Most tools work fully in the browser. The QR generator uses the QRServer API to create QR images, so that one tool needs an internet connection.
